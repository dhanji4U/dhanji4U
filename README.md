# Dhanji Bhagat

Founder and Principal Engineer at [Emiote](https://emiote.com). I build and ship production web platforms, native desktop applications, and open-source developer tooling.

## What I Build

- **[Ankik](https://emiote.com/ankik)**: Native desktop accounting application with multi-tenant cloud sync, engineered for startups and SMEs.
- **[Sysper](https://emiote.com/sysper)**: Native desktop disk cleaner for developers. Built with Tauri v2, Rust, and Rayon concurrency. Moves abandoned dependencies and compiler caches to the OS Trash with triple-layer secret exclusion.
- **[Emiote](https://emiote.com)**: Product design and engineering studio. We build and launch production software with founders.
- **[Agent Skills](https://emiote.com/skills/)**: Executable open-source markdown skill definitions for AI coding agents.

## Core Stack

- **Desktop**: Tauri v2, native OS APIs (Windows IFileOperation, macOS NSFileManager)
- **Systems & Backend**: Rust, Node.js, TypeScript, PostgreSQL, Cloudflare Workers
- **Frontend**: Next.js, Astro, React, Tailwind CSS
